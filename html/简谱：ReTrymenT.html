PS：上周想用番茄简谱渲染另一个谱子，结果发现番茄简谱官网的域名过期了。去别的地方下载了番茄简谱本地版，发现本地版只是个 Steam 客户端那样的浏览器内核，需要连上官网才能用。所以尝试了下其他几个文本标记简谱的工具。

首先尝试的是 jianpu-ly，这是个 Python 程序，先将简谱转成 lilypond（GNU 五线谱排版软件）的渲染脚本，再用 lilypond 渲染。结果搞了半天都没搞成功，后面上 WSL 才搞定，果然 MinGW 编译的软件没几个不水土不服的。用它渲染了下简谱，感觉效果一般，而且还会丢失升降符号（开始以为是 bug，去 github 提了 issue，开发者倒是很热心，几天之后就回复我了，说是他认识的中国管弦乐队采用18世纪西方传统规则，同一小节里重复的升降号省略，所以他也默认采用了这个规则。这个规则可以在脚本里改环境设置。不过我个人认为用简谱的 90% 都是中国业余票友吧，哪里懂什么西方传统规则），所以还是放弃了。

后面又尝试了 Sparks NMN，感觉确实不错。本地版就是完全可以断网使用的桌面网站，渲染的效果也挺好，功能也很强，并且开源，作者还一直在更新。但美中不足的是导出功能太鸡肋了，只能导出 html，想导出图片还得先 html 转 pdf 再 pdf 转图片（也可以用浏览器全页截图直接 HTML 转图片，但转出来的图片白底太多，显示效果不好），很麻烦。看起来开发者似乎是一个人开发的这个软件，挺牛逼的，不过这个工具不太出名，Github 上星数不是很多。

虽然番茄简谱的开发者几天过后就把域名续上了，但番茄简谱的渲染效果说实话一般，页面也有些小 bug，更主要是担心哪一天开发者弃坑了。所以以后本博客可能会改为提供 Sparks NMN 脚本和其渲染的简谱图片。
